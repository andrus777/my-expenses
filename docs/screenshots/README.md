# Portfolio screenshots

Screenshots are intentionally generated from the running application instead of committing stale
mockups. Use the demo seed, launch the debug build in a Pixel emulator with a current stable API,
and capture PNGs at the same resolution and light theme.

Recommended set:

1. `01-login.png` — login screen.
2. `02-home.png` — summary, recent expenses and budget progress.
3. `03-add-expense.png` — fast amount/category flow.
4. `04-history.png` — populated local-first history.
5. `05-subscriptions.png` — upcoming payments and history.
6. `06-receipt-preview.png` — completed fake-provider preview.
7. `07-statistics.png` — monthly summary and timeline.
8. `08-budgets.png` — normal, warning and exceeded states.

Android Studio: **View > Tool Windows > Running Devices**, then use **Take Screenshot**. Remove
notification content and personal data before publishing. Add the selected images to this directory
and replace the README placeholder links only after visually checking them.
